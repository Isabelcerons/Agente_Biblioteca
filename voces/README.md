# Modelo de voz

`es_MX-claude-high.onnx` es el modelo en español de México usado por la síntesis de voz del agente. Se distribuye desde [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices/tree/main/es/es_MX/claude/high), cuyo repositorio declara licencia MIT. Se conserva el archivo de licencia de Piper en `PIPER-LICENSE.md`.

El archivo `es_MX-claude-high.onnx.json` contiene los metadatos necesarios para cargar el modelo.
